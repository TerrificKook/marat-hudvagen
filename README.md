# Марат / Худваген с водителем для съёмок

Выбран и завершён вариант C. [Открыть сайт](https://terrifickook.github.io/marat-hudvagen/).

Первый экран объясняет услугу: доставка реквизита и материалов, рабочая база художественного цеха на площадке, Марат за рулём. Цена и связь видны сразу. Ниже - раскрывающийся фургон, реальные фотографии, видео с точек и условия. В шапке доступны MAX, Telegram и звонок. Год автомобиля не указан.

## Структура

- `index.html` - основная страница C. Canonical, Open Graph, robots и sitemap настроены для текущего адреса GitHub Pages.
- `site-final/index.html` и `concepts/concept-c/index.html` - сохранённые адреса C, noindex.
- `site-final/site.css`, `site-final/site.js` - финальная подача и галерея.
- `concepts/shared/` - базовый дизайн, контакты, Canvas-модель и трансформация.
- `site-final/assets/` - настоящие фото; `assets/fonts/` - локальный Inter с лицензией.
- `concepts/` - архив сравнения вариантов A, B и C. `site-final/brief.html` - прежняя подробная версия.
- `notes/qa-report.md` - проверки и ограничения; `notes/blockers.md` - дальнейшие настройки.

Статический HTML/CSS/JavaScript без сборки и зависимостей. Форм для ввода данных нет. Нет аналитики, серверного приёма заявок и автоматической брони.

На всех страницах есть уведомление «О данных на сайте» с кнопкой OK. После нажатия в браузере хранится одна отметка. [Подробное пояснение](site-final/privacy.html) раскрывает работу ссылок и GitHub Pages. Для юридической политики обработки обращений в мессенджерах нужны подтверждённые данные оператора.
