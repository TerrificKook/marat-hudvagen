## Структура

- `index.html` - основная страница C. Canonical, Open Graph, Service JSON-LD, robots и sitemap настроены для www.hudwagen.ru. Генератор сохраняет файл Яндекс Вебмастера и метатеги Google/Bing при следующей сборке. Явный `/index.html` перенаправляется на `/` с сохранением параметров запроса.
- `site-final/index.html` и `concepts/concept-c/index.html` - сохранённые адреса C, noindex.
- `site-final/site.css`, `site-final/site.js` - финальная подача и галерея.
- `concepts/shared/` - базовый дизайн, контакты, Canvas-модель и трансформация.
- `site-final/assets/` - настоящие фото; `assets/fonts/` - локальный Inter с лицензией.
- `concepts/` - архив сравнения вариантов A, B и C. `site-final/brief.html` - прежняя подробная версия.
- `notes/qa-report.md` - проверки и ограничения; `notes/blockers.md` - дальнейшие настройки.

Статический HTML/CSS/JavaScript без сборки и зависимостей. Форм для ввода данных и серверного приёма заявок нет. Яндекс Метрика включена 03.10.2026 по разрешению владельца (отдельный счётчик 113163390) и загружается только после согласия посетителя. Автоматической брони нет.
