# Марат / Худваген с водителем

Три интерактивные дизайн-концепции. Сайт статический: HTML, CSS, JavaScript, Canvas/SVG. Сборки и установки пакетов нет.

## Смотреть

- [Все варианты](https://terrifickook.github.io/marat-hudvagen/)
- [C / Внутри больше](https://terrifickook.github.io/marat-hudvagen/concepts/concept-c/) - рекомендуемый: объёмная машина раскрывается по прокрутке.
- [A / За кадром. В деле](https://terrifickook.github.io/marat-hudvagen/concepts/concept-a/) - редакционный коллаж, хлопушка и монтажный стол.
- [B / Город. Мотор. Поехали](https://terrifickook.github.io/marat-hudvagen/concepts/concept-b/) - игровая изометрическая карта, фургон ездит между точками.
- [Полный сайт C](https://terrifickook.github.io/marat-hudvagen/site-final/).

Сейчас согласовывается уникальный дизайн. SEO и итоговый домен - следующий этап. Страницы помечены noindex.

## Локальный запуск

```sh
node serve-local.js
```

Открыть http://127.0.0.1:8000/. Для другого порта: `PORT=8001 node serve-local.js`.

## Структура

- `concepts/` - сравнение и три направления.
- `concepts/shared/experience.css` - адаптивный дизайн.
- `concepts/shared/experience.js` - монтаж, поездки, окно MAX, копирование.
- `concepts/shared/van-3d.js` - авторская объёмная иллюстрация и трансформация.
- `site-final/index.html` - полная версия выбранного C.
- `site-final/brief.html` - прежняя подробная страница и генератор текста задачи, сохранённые отдельно.
- `site-final/assets/` - реальные фото в WebP; `assets/fonts/` - локальный Inter и лицензия.
- `notes/` - решения, референсы, открытые вопросы и выполненные проверки.
