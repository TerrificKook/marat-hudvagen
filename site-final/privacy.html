О данных на сайте

Это пояснение относится к сайту Марата по адресу terrifickook.github.io/marat-hudvagen/.

Что сохраняется в браузере

Когда вы нажимаете OK в уведомлении, сайт записывает в localStorage вашего браузера одну отметку: marat_data_notice_ok_v1=1. Она нужна только для того, чтобы не показывать уведомление повторно. В ней нет имени, телефона или текста сообщения. Удалить отметку можно через настройки браузера, очистив данные сайта.

Форма и обращения

Форма на сайте помогает составить текст для Марата. Введённые даты, маршрут и задача не отправляются на сервер сайта и не сохраняются в localStorage. Текст остаётся на открытой странице, пока вы сами не скопируете его. Кнопки звонка, Telegram, MAX и канала открывают соответствующие сервисы по вашему нажатию. Передавая Марату сведения через них, вы используете правила выбранного сервиса.

Хостинг

На сайте сейчас нет аналитических счётчиков и рекламных пикселей. Страницы размещены на GitHub Pages. По информации GitHub, при посещении GitHub Pages фиксирует IP-адрес для безопасности; обработка GitHub описана в его заявлении о конфиденциальности.
